# AI Vision Internship Assignment

At **Visomni**, we build intelligent vision systems that make industries safer, efficinent, and loss-proof.

This should take **4–6 hours**. It’s okay if not perfect; we care more about your effort, clarity, and ability to ship.

---

## Goal
Take any short video (like a cctv camera / cricket match) and build a program that:  
1. Detects people in each frame.  
2. Gives them IDs so you can follow the same person across frames (tracking).  

(Bonus Features)

3. Defines a **zone** (a polygon you choose).  
4. Logs when each person **enters, stays more than X seconds, and exits** the zone.
